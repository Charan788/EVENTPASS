# EventPass

EventPass is a simple event ticketing web app where every ticket is a QR code that works only once.

This is our project for the Product Development track of the OJT program at Polaris School of Technology.

**Status:** Just getting started. Nothing is built yet, this README describes what we plan to make.

## Why we're building this

At busy events, entry staff often check tickets from screenshots or printouts. That means the same ticket can be used twice, and the line at the gate gets slow. We want to build a small app where each pass can be used only once and the staff get a clear result when they scan it.

## What we plan to build

- Organizers can create events with a name, date, venue and capacity
- Organizers can issue passes to attendees, and each pass gets its own QR code
- Staff can scan a pass at the door and see if it is valid, already used, or invalid
- The first valid scan marks the pass as used, so a second scan is rejected
- A dashboard shows how many passes were issued, how many people checked in, and how many spots are left
- Organizers can revoke or reissue a pass
- Attendees can open their pass and see its status
- Works on both phone and laptop

## Tech stack

- HTML, CSS, JavaScript
- Bootstrap 5
- localStorage to save data in the browser (no backend)
- Git and GitHub

## Scope

 It will not have a real backend, database or payments, and the QR validation will be simple and run in the browser.
